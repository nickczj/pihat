7.3-inch & 4-inch E-Ink / ePaper Display HAT Adapter Board

Basic function

  • Driver circuit: Peripheral Boost Circuit
  • Supporting screen: 7.3 inch
  • Matching motherboard: STM32、ESP32-L、ESP8266-L、Arduino UNO-L

 

 

 

Basic parameters

  • Outline size: 47x32mm
  • Communication Interface: SPI
  • Screen Interface: 50PIN 0.5mm
  • Key Components: SI1308EDL, MBR0530
  • DIP Switch: None
  • Operating Voltage: 3.3V
  • Operating Temperature: -20~70℃

 

 

 

Auxiliary Functions

  • Boost Detection: Reserved boost detection points for convenient fault diagnosis.
  • Design Reference: Initial design reference for user product design.

 

 

 

 

 

 

 

Display Pin Functions

Pin Name Function Description
BUSY Busy status output pin
RES External reset pin (low = reset)
D/C Data/Command control pin (high = data, low = command)
CS SPI chip select pin (active low)
SCK SPI clock signal line
SDI SPI data input line
GND Ground
3.3V Power supply (positive)
